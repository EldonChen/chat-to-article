# 笔调：多版起草与行文

## 先出多版，让作者挑

只问作者想要什么风格，作者很难说清。让他看几段写好的样稿再挑，容易得多。本篇还没有选定笔调时（`show-block` 会提示），第一块不要只写一版。

```bash
python3 <skill>/scripts/cta.py variant-brief --article articles/<slug> --block b001
python3 <skill>/scripts/cta.py presets
```

`variant-brief` 会说明这块要出几版，以及能不能出「按你的偏好」那一版，并列出可用的偏好材料。

怎么配版本：

- 默认出 3 版，每版写的是同一块、同样的主张，只有笔调不同。
- 有偏好材料时，其中一版必须是「按你的偏好」。偏好材料包括：风格档案里生效的规则和范文、本篇已记下的偏好，以及以往文章里留下、还没确认的候选。这一版要把这些偏好落实到句子上，而不是套某个内置笔调。
- 其余几版从 `styles/presets.json` 里挑。挑和本篇文体相容、彼此差别明显的笔调。例如工程复盘可以配「跟同事复盘」和「工程笔记」，不要配两个都很正式的笔调。
- 写作计划里有 `styleAxes` 时，内置笔调那几版也要顺着它，不能和已确认的偏好冲突。

给作者看时，每版标出笔调名和一句话差别，例如「更口语，保留了当时的犹豫」。有 `review_variants` 工具时用它，否则在对话里依次贴出几版，再用结构化提问工具让作者选，并允许作者说「A 的开头加 B 的结尾」这类组合。

作者选定后：

```bash
python3 <skill>/scripts/cta.py pick-variant --article articles/<slug> --block b001 \
  --voice colleague --body-file chosen.md --note "作者喜欢它保留了原话"
```

`--voice` 填内置笔调 id，「按你的偏好」那版填 `profile`，组合或作者自拟的填 `custom` 并在 `--note` 里写清楚。命令把选中的正文存成草稿，在 `writing-plan.json` 里记下 `voice`，并把这次选择记成本篇偏好。然后把作者对各版的评价（喜欢哪里、不喜欢哪里，没选中的那几版也算）按 [preferences.md](preferences.md) 记下来，再把选中的这版交给作者精修。

什么时候不再出多版：

- 作者选过一次之后，后面的块按选定的笔调和已记下的偏好写一版。
- 第二节的第一块可以再出 2 版：一版按当前笔调和偏好写，另一版顺着作者改动的方向再推进一步。只在作者精修第一节时还在大量改语气的情况下这样做。
- 作者说「就这样写」或「不用再给我选了」，就不再出多版。

## 机械腔从哪来

下面这些写法会让文章读起来像机器写的。起草和自查时逐条对照：

- 每段长度差不多，结构都是「主题句、展开、小结」。
- 段末加一句总结或升华，例如「这正是……的关键所在」。
- 连接词堆砌：首先、其次、此外、与此同时、综上所述。
- 三点式和对称排比，只是为了凑整齐。
- 聊天里的具体细节（数字、报错、作者的原话、当时的犹豫）被抹成抽象概括。
- 每一节都套「背景、问题、方案、总结」。
- 限定词过多：在一定程度上、可能、某种意义上。
- 作者习惯说「我」，正文却写「我们」或「笔者」。

聊天记录是最好的笔调来源。作者在聊天里怎么说一件事，正文里尽量保留那个说法。

## 篇幅跟着内容走

不要为了凑字数或控制字数而增删内容：

- 块是一个意思完整的单元，不是一个段落。一块可以只有一段，也可以有好几段。
- 一节放几块、一块写几段，按这一节的主张和材料多少来定，不要在各节之间平均分配。
- 段落长短跟着意思走。一句话能说清的就单独成段；一个例子要展开讲，就让那一段长一些。
- 主张多、材料足的节自然写得长，材料少的节写短一点，不要用空话把它撑长。

作者在批注里提到长短，例如「这段太长」，就把它当成偏好记下来。不要把它推广成固定的字数限制。
